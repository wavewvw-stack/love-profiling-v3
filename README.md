# 恋愛プロファイリング Ver.3

4〜26人対応のスマホ向けリアルタイムWebゲームです（4人以上で開始）。

## 起動
Node.js 18以降を用意し、このフォルダで `node server.js` を実行。`http://localhost:3000` にアクセス。

## 遊び方
ホストがルームを作成し、招待URLを共有。全員が名前を入力して参加します。8ラウンドで男性視点・女性視点を交互に切り替え、全員が匿名でセリフを回答します。自分以外の回答からベスト3（3・2・1点）を選び、次に他人の回答者を全員推理。正体公開時にそのラウンドの刺さり得点最下位1人が自作セリフを実演します（任意、パス可）。

## 採点・同点
推理点は各ラウンド `10 × 正解人数 / (参加人数 - 1)`、刺さり点は投票で得た点数。実演者はその回の刺さり得点が最も低い人。同点なら推理正解数の少ない人、それでも同点ならランダム抽選。

## 公開方法
GitHubリポジトリに `server.js` と `index.html` をアップロード。RenderなどのNode.js対応ホスティングでWeb Serviceを作り、Start Commandを `node server.js` に設定します。ホストのURLをLINEで共有できます。

## 注意
ルーム状態はサーバーメモリに保存されます。サーバー再起動・スリープで進行状況が消えます。単一サーバープロセスでの利用を想定し、複数インスタンス構成では同期しません。参加者IDは各端末のlocalStorageに保存されます。HTTPS公開推奨。大人数の動作・本番運用は別途検証してください。飲酒・実演は強制しないでください。
